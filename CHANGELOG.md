# BoltWorks Local AI 0.6.19

- The default build provides the general-purpose desktop app, local CLI, coding workspace, and Mini REA.
- Computer Check compares local CPU model speed, memory use, and basic instruction following.
- Mini REA inspects executables, resources, firmware signatures, embedded strings, and local Ethernet devices. The optional ILSpy backend decompiles managed .NET assemblies.
- Separate Windows XP demos cover binary inspection, offline inference, and experimental C code generation and compilation.

See the [build guide](BUILDING.md), [release audit](RELEASE-AUDIT.md), and [XP demo guide](legacy/XP-DEMO.md).
