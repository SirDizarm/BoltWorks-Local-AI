# Quick start

Build the app and set up the runtime folders using [BUILDING.md](BUILDING.md). Open BoltWorks-Local-AI.exe.

## Choose models

The left panel has Chat, Read images, and Create pictures slots. Choose and lock only the models you plan to use. Locking saves a choice. The app loads models when it needs them. For a vision model, also provide the matching mmproj file. Use **Check this computer** to compare local chat models.

## Use a workspace

- **Chat** runs your local text model. Attach an image with a compatible Read images assignment.
- **Work on code** opens a folder for file analysis and editing. Review proposed commands before running them. This workspace also opens the EXE/DLL, firmware, legacy import, and Ethernet tools.
- **Create pictures** uses a compatible image checkpoint. Enter a prompt, optionally choose a starting image, and save the generated PNG. See the [known red tint issue](README.md#current-limits-and-compatibility).

Use the [README](README.md) for detailed guides. For scripting and optional editor support, see the [integration guide](INTEGRATING.md).
